# Результаты нагрузочного теста

Контрольный запуск выполнен 8 ноября 2026 года на отдельном локальном Docker-стенде. Рабочий сайт в Yandex Cloud не использовался.

## Условия

- 100 разных пользователей и 100 одновременно открытых WebSocket-соединений
- 50 личных переписок, пользователи общаются парами
- Основная фаза: 60 секунд; заданная пауза между операциями пользователя: 5000 мс
- Перед основной фазой: регистрация, вход и создание переписок
- Docker Desktop: 16 доступных CPU и около 7,4 ГиБ RAM
- Backend: Java 21, Spring Boot 4.0.8, heap до 768 МиБ
- PostgreSQL 17, Elasticsearch 9.2.8 с heap 512 МиБ, генератор нагрузки Node.js 24.22.2

Это повторный прогон на уже запущенном стенде. Данные предыдущего прогона оставались в отдельной тестовой базе. Каждый новый запуск создаёт новые аккаунты.

| Показатель | Значение |
|---|---:|
| Пользователи, прошедшие вход и подключение WS | 100 |
| Максимум одновременных WS-соединений | 100 |
| HTTP-запросы подготовки | 250 |
| P95 HTTP при подготовке | 950,89 мс |
| HTTP-запросы основной фазы | 2556 |
| Неуспешные HTTP-запросы | 0 (0%) |
| P95 HTTP основной фазы | 115,30 мс |
| Принятые сервером сообщения | 1278 |
| Доставленные собеседнику через WS сообщения | 1278 (100%) |
| P95 доставки через WS от начала отправки | 241,33 мс |
| Разрывы WS / некорректные события | 0 / 0 |
| Сообщения, доставленные постороннему пользователю | 0 |

Все заданные пороги прошли, код выхода — `0`. P95 означает, что 95% измерений не превышают указанное время. Подготовка не включена в HTTP-метрики основной фазы.

Запуск:

```powershell
docker compose -p minechat-loadtest --env-file loadtests/.env -f compose.load.yaml --profile test run --rm --no-deps loadtest
```

Полный JSON-отчёт сохраняется локально в `target/load-results/latest.json` и не публикуется в Git. Это результат конкретного сценария и компьютера: 100 подключённых пользователей не означают 100 запросов в секунду и не подтверждают такую же производительность облачной VM.
